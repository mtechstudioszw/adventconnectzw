How to install on Android

  1. Tap "Download APK" above. Your browser saves the file.
  2. Open the file from the notifications shade or your Downloads folder.
  3. If Android asks, allow "Install unknown apps" for your browser (one-time prompt — it's expected for any app not on the Play Store yet).
  4. Install. Open Advent Connect ZW. Sign up with your email or Google.

Is this safe?

Yes. The APK is built by GitHub Actions directly from the open source at github.com/mtechstudioszw/adventconnectzw on every commit. You can read the exact code before installing if you want to.
